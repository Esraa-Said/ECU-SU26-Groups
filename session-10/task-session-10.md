# Session Task: Project Idea Research & Planning

## 📌 Task Overview

In this task, you will research and plan a complete web application project idea that includes real-world features such as **CRUD operations, user authentication, authorization, and file/image handling**.

The goal of this task is to practice analyzing a project before starting development by identifying its features, users, pages, and UI design.

---

# Task Requirements

## 1. Choose a Project Idea

Search for a suitable project idea that can be implemented as a full-stack application.

Your project must include:

* CRUD Operations
* User Authentication
* User Authorization (Roles & Permissions)
* Image/File Upload
* Database Management
* Different User Roles

Examples of project ideas:

* E-Commerce Platform
* Learning Management System
* Hospital Management System
* Restaurant Management System
* Real Estate Platform
* Event Management System
* Task Management System
* Booking System
* Social Media Application

You can choose any other idea, but it must contain the required features.

---

# 2. Define Project Description

Write a short description explaining:

* What problem does your application solve?
* Who are the target users?
* What is the main purpose of the application?

Example:

> "A medical appointment system that allows patients to book appointments with doctors, while doctors can manage schedules and administrators can manage users and system data."

---

# 3. Identify Users and Roles

Define all users in your system.

For each user, specify:

* Role name
* Permissions
* Available actions

Example:

| Role    | Permissions                         |
| ------- | ----------------------------------- |
| Admin   | Manage users, doctors, appointments |
| Doctor  | Manage profile, view appointments   |
| Patient | Book appointments, update profile   |

---

# 4. Define Main Features

## Authentication Features

---

## Authorization Features

## CRUD Features

Identify the resources in your application and their operations.

Example:

### Products Management

Create:

* Add new product

Read:

* View all products
* View product details

Update:

* Edit product information

Delete:

* Remove product

# 5. Image/File Upload Features

Define where your application needs file uploads.

Examples:

* User profile picture
* Product images
* Doctor certificates
* Post images
* Documents

* File type
* Maximum size
* Who can upload it

Example:

```
User Profile Image:

Allowed:
- JPG
- PNG

Maximum size:
- 5 MB

Uploaded by:
- Users
```
